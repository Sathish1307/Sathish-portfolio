# Sathish Kumar M — Engineering Portfolio

## Run locally
1. Extract the full ZIP folder.
2. Keep `index.html`, `style.css`, `script.js`, `standing-portrait.png`, and the `media/` folder together.
3. Open `index.html` in Chrome, Edge, or Firefox.

## What's new in this edition
- A small animated flying engineering scout follows a curved path across the viewport as the visitor scrolls. Its status label changes with the current portfolio area.
- Removed the vertical section-progress rail. The normal top navigation remains available.
- Hovering over project, experience, achievement, skill, education, index, and workbench readout cards makes them lift, tilt, reveal a compact label, and catch a cursor-following signal highlight.
- Keyboard focus gets the same card emphasis as pointer hover.
- Reduced-motion preferences are respected.
- GIM-RBS simulation walkthrough remains embedded in the Projects section under `media/`.

All plot curves in the workbench are illustrative, not measured simulation data.
